# 00 范围与约定

## 1. 需求来源与优先级

本包由当前会话明确要求、项目交接、产品文档、正式代码、现有测试及原型核对整理。最新明确用户决定优先；业务看现行 PRD 与总控，实际已交付细节看 apps/ 与测试，外观看正式网页及视觉要求；prototype/ 只作参考。发现冲突不得自行选择方便实现的一项，先查 08；新冲突补入 08 并记录理由。

本包是一份可执行基线，不是历史全量复制。原文仍位于 docs/product/、docs/engineering/（路径相对仓库根），关键差异已在 08 裁定为本次默认实现口径。没有冻结的正式生产规格，先按当前本地实现保留，不阻塞合成数据开发，不宣称已经获得生产准入。

## 2. M1 必须完整保留

- 手机号验证码登录；本地明确标识的模拟验证码；合成体验码环境；PNVS 平台生成与远程核验适配；会话、登出、跨设备。
- 年满 18 岁及身体数据同意；昵称、12 个 emoji 头像；首次资料与后续编辑分开。
- 首页按当前小组切换主操作，登录与邀请链接的账号感知分流。
- 创建、动态邀请、开营前加入／退出／重新加入、开始权限交接、空组关闭。
- 身高／起始体重准备及目标计算、开营前编辑、改周期后全员重新确认、开始预览与正式开始。
- 进行中中途加入、剩余天数门槛、最多 8 人、一账号最多一个未结束小组。
- 本人当天记录、公斤／斤、覆盖确认、版本冲突、结果未知核对、跨日与截止保护。
- 小组概况、准备起点展示、个人 7／28 天分析、全员三维度同图、记录明细、结束复盘、历史。
- 第 3／4 天的原有全员站内提示及服务端展示回执。
- 本人 JSON 导出、支持请求提交／查询及开发者处理工具、账号注销、独立删除清单及恢复重放。
- 手机优先视觉、胶囊动效、固定按钮、安全区、轮询恢复、账号切换清理。
- 环境隔离、健康检查、备份恢复与必要运维工具的等价能力。

## 3. 技术目标与新工程约定

采用模块化单体，非微服务：Java 21 + Spring Boot + Spring Security + Spring Session；MySQL + MyBatis-Plus + Flyway；Redis + Redisson；RabbitMQ + Spring AMQP；Vue 3 + TypeScript + Vant；图表使用 ECharts 或等价可控实现；Maven Wrapper、前端包管理锁文件、Docker Compose、Nginx、CI。

具体受维护稳定版本在 B0 检查兼容性后锁定，写入 05；不照抄旧图中的 Spring Boot 2，不在本包虚构当前依赖版本。优先使用成熟框架机制，不手写完整认证框架。JWT、微服务、服务注册、ES、支付、模型调用均不在本次默认范围。

- 新后端 `apps/java-api/`；新前端 `apps/web-vue/`；新部署 `deploy/java/`；新工程脚本 `scripts/java/`。
- 旧 `apps/api/`、`apps/web/`、`packages/`、`db/`、`prototype/` 保留；不悄悄改旧产品来迎合新实现。
- API 尽量兼容 `/api/v1` 和当前字段，新前端先遵守本包的契约，后端完成后导出可验证的 OpenAPI 文档。
- M1 必须真正使用 Redis 共享登录态并验证双实例。实时动态（B10，SSE + Redis Pub/Sub）与快照读取优化、可选统计缓存（B9）属 M1 之后的批次：前者是产品功能，后者不改接口契约。Redisson、MQ 的业务验收留到 M2。这只是实施顺序，不删掉目标技术栈。Redis 的用途边界见 [11 Redis 使用方案](11-Redis使用方案.md)，实时方案见 [12](12-实时动态与事件推送.md)。

## 4. 不改变的产品决定

默认 14 天，14／28／56 预设，自定义 14–90；四档强度；最多 8 人；至少 2 人且全员准备才开始。保留 bmi22-piecewise-v1，不加低 BMI 门槛／目标截断。开营后不提供普通退组、踢人、提前结束；不增独立撤回共享入口。保留导出、注销与支持。

不做历史补录、历史编辑、离线自动提交、健康评分、聊天、资金竞赛、奖金、付费分析。M2 新功能有独立开关和验收，不能覆盖现有第 3／4 天提示规则。

## 5. 开发与交付约定

所有合成账号与库由新工程创建；开发包不得带入真实手机号、验证码、体验码、数据库、备份、密钥、管理口令或私有连接资料。只使用占位配置和供应商替身运行自动化。用户提供配置也不等于授权自动发送短信或切换线上。

每个任务必须有真实运行结果、失败结果与未完成项。开发者管理功能默认用受控 CLI，不新增可公开访问的后台。先提供可运行的完整产品，再整理真实简历条目；不承诺高并发规模和性能提升数字。
