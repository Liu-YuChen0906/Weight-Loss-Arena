## 一批工作的执行步骤

1. 明确当前任务及对应验收ID，读取本包相关章节及源参照；核对源摘要变化。
2. 编写实际代码／结构升级／必要配置，沿当前规则实现；不为了快删减导出、提示、历史、异常和隐私。
3. 跑有意义的单元／集成／浏览器检查；故障时追到实际原因，环境问题和业务失败分开。
4. 在本包evidence/下保存脱敏结果和合成截图；按06记录命令、环境、结果与未测边界。
5. 更新本表、CHANGELOG和项目开发交接；说明下一批可直接执行的动作。无代码／仅文档不得标开发任务完成。
