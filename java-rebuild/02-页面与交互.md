# 02 页面与交互

M1 用 Vue 从头实现，保留当前体验。正式 `apps/web/` 是功能参照；原型用来理解布局，不能直接复制静态账号、示例邀请码、占位算法和 localStorage。设计不要求照搬 Vant 默认蓝色外观。

## 1. 全局视觉与基础组件

| 项目 | 要求 |
| --- | --- |
| 品牌 | 上秤；不恢复旧名“轻友赛”，Logo 未选定，不自行接入候选 |
| 色彩 | 背景#FCFCFD，白卡#FFF，主色#CF4938，首页主按钮#E25B49，浅珊瑚#FFF0EC，正文#29272C，次文#7C7880，边框#EEEBEE，错误#A63838 |
| 字体与数字 | 系统中文无衬线；tabular-nums；体重两位小数、单位弱化；字号以现有样式为基准：正文15、移动标题26、首页40（极窄36）、记录输入52、目标34–36px |
| 卡片与按钮 | 卡片圆角16px、常规内边距20px、间隔16px，无明显阴影；主按钮圆角12px，触控区域≥44px；不撑高卡片造空白 |
| 响应式 | 760px断点；手机单列横边距20px；桌面最大1120px、左导航200px、间距48px，表单最大560px；320／375／390／430／1024px验收 |
| 固定区 | 创建／加入／大厅主动作固定底部；记录保存固定在底部导航上方；预留safe-area与内容底垫，键盘不挡字段和动作 |

## 2. 页面清单（全量）

| ID | 页面／入口 | 内容与动作 | 必须覆盖的状态 |
| --- | --- | --- | --- |
| P01 | 首页 `home` | 产品名；当前组返回或创建／加入；历史、账号支持、隐私 | 匿名、无组、LOBBY、ACTIVE、只有结束历史 |
| P02 | 手机登录 `login` | 手机号、验证码、获取码、登录；本地显示“未发送短信”模拟码 | 未发／冷却／错误码／超时／额度不足／登录过期 |
| P03 | 体验码登录（test环境） | 专属合成体验凭据、进入测试；不显示手机号输入 | 错误凭据、来源错误、重新登录同账号 |
| P04 | 首次资料 `profile` | emoji、昵称、两个未预选确认、查看数据说明 | 未同意拒绝、保存失败保留输入、确认后继续原去向 |
| P05 | 创建 `create` | 名称介绍、周期、强度、固定创建；先确认共享再提交 | 输入过程、非法周期、取消确认、极高取消、已有组 |
| P06 | 输入邀请码 `join` | 12位输入、查看小组 | 空／非法／失效；已有组优先回组 |
| P07 | 邀请详情 `invite` | 最小小组信息、人数／8、周期强度、剩余天数、共享确认；ACTIVE准备表单 | 匿名登录继续、满员、13／14天、跨日、已是成员 |
| P08 | 大厅 `lobby` | 名片卡、成员及准备、本人准备卡、邀请、owner编辑、退出、固定开始 | 一人、未全员准备、普通成员、权限交接、周期变更 |
| P09 | 小组 `group` | 截止／进度、无记录本人起点卡、成员状态与最新读数、邀请、站内提示 | 起点、0／1／多条记录、未更新、到期自动复盘 |
| P10 | 记录 `record` | 单位胶囊、大数字输入、只读目标、保存 | 当日预填、覆盖确认、冲突、未知核对、跨日、已结束 |
| P11 | 个人分析 `analysis/:userId` | 姓名标题、原始体重图、7／28天、记录天数／覆盖率、明细入口、目标 | 无／单点／准备起点、缺日、他人成员、历史期 |
| P12 | 小组数据 `data` | 全员同图、7／28天、体重／变化／比例、紧凑成员数值 | 无实际记录起点提示、部分成员无数据、8人、快速切换 |
| P13 | 复盘（group的ENDED状态） | 起止日、全期覆盖率并列排名、成员分析、再组一期 | 全期90天、晚加入、无记录、注销后重算 |
| P14 | 历史小组面板 | 本人最新100个结束期，名称日期周期，点击复盘 | 空、同名不同期次、当前已有另一组 |
| P15 | 账号与支持面板 | 脱敏手机号、昵称、改名片、隐私、本人导出、提交／查支持、登出、注销 | 取消、失败重试、切号、删除后旧页面不可读取 |

原Hash路由支持 room 查询参数恢复当前或历史组；Vue 可使用等价Hash路由，保留 `/?invite=` 外部入口和刷新恢复。个人分析属于小组，导航仍选中“小组”。LOBBY不显示开始后导航；开始后仅“小组／记录／数据”，没有独立“我的／分析”Tab。

## 3. 关键表单与弹层

- 创建：名称实际value为空，默认名只作为placeholder。自定义是第四项本身，输入即取消预设选中，失焦／提交才报错，切预设时不抢先弹错；低／中／高直接选，极高弹确认，取消保留原档。创建确认显示最终名称、天数、强度，不显示未确定日期；共享同意未勾选时禁用确认。
- 邀请：展示真实动态邀请码、链接、复制按钮和手动复制后备，不出现QY2026占位码；非成员详情不显示身体数据，不因登录而自动加入。
- 名片：整张“昵称与头像”卡可点；12 emoji手机6列，<360px为4列；保存失败保留草稿，后台轮询不冲掉编辑内容；已有同意不重复勾选。
- 准备：未准备显示整行“填写身高体重”；已准备显示起始→目标及整行修改按钮，三位数不溢出。底部面板两个字段、预览目标、确认／取消；目标只读，取消保留旧值。身高不显示在准备结果卡。
- 开始：预览最新名称、周期、强度、起止日期，暖色日期卡分左右；确认／再等等，跨日或版本变化需重开预览。固定开始按钮不随准备卡高度跳动。
- 记录：不额外显示标题下日期；默认单位kg；切换单位立即更新数值与目标、不保存、不反复舍入内部kg。覆盖弹窗标题“修改今日记录”，两卡并排：旧暖灰#F7F5F4、旧值#8B8589；新浅珊瑚#FFF0EC、新值#CF4938；原记录／修改为、中央箭头、确认修改／取消，不加顶部叉号、日期和解释段落。
- 明细：独立底部面板、倒序日期／体重，当前没有真实补录字段，不生成假“补录”状态；内部滚动最大约50dvh，底部关闭常见，不重复姓名区间说明。
- 注销：输入确切确认文字、确认／取消；成功清Cookie及客户端全部私有状态；不展示“所有备份已擦除”。导出下载JSON，不偷换为付费Excel功能。

## 4. 图表与少量数据

个人实际点可点按及键盘Enter查看日期、体重；准备点另标“起始体重·准备时填写”。小组图不要求点按详情，不能强加工具栏。迷你线只展示不可点，头像／姓名可点。

小组颜色顺序 #CF4938、#6B80C6、#B96491、#9471BC、#32978F、#C18A35、#628D50、#5C91B2；颜色同时对应姓名与数值，不只靠色识别。实际日期间距绘图、缺失不补0、单点居中、正负变化保留，跨0显示基准线。实际点边界与文档轴范围差异见08。

选区间和维度同时更新曲线、轴单位、成员末值；快速请求只接受最新结果，失败回到已加载范围；不能让旧请求覆盖新选择。不显示最低／最高、平滑趋势、健康评分、AI入口或独立参与卡；复盘的覆盖率参与列表仍保留。

## 5. 页面状态与网络

- 前端业务状态来自API，不用数组首项当本人、不写死角色和今天；准备预览可本地算，提交后以服务端目标为准。
- 首次启动读取config再恢复me，config失败不默认降级本地模式。账号切换、登出、注销、401或CSRF变化清理用户数据、弹层、待核对请求；迟到旧会话响应不得重新显示旧数据。
- 前合约5秒轮询整份快照；失败退避最多60秒，首次失败简短提示；后台暂停，回前台恢复。正在输入记录、编辑名片或弹层表单时不得因轮询丢草稿。**B10 计划改为事件推送为主、60 秒版本轮询兜底**（见 [12 实时动态与事件推送](12-实时动态与事件推送.md)）；在 B10 实施前，本节行为保持不变。
- 普通写操作防重复点击；不同图表筛选可连续操作，只认最后一次请求。未知保存按F07核对，不能简单提示“保存失败”或生成新键重发。
- 验证码倒计时按手机号的绝对截止时间维护，页面重绘和切后台不丢；失败／429仍按retryAfter倒计时，刷新后首次429恢复实际剩余。无响应保守等60秒，不自动重发。
- 敏感数据和登录令牌不进localStorage、URL、公共缓存、埋点；无离线Service Worker。刷新不承诺恢复未提交身体数据。
