## 开发时保留的边界

- 最新决定：不设计独立撤回共享；保留导出、注销和支持。当前目标算法保持，不增加低 BMI 限制。历史／身高、按期删除、备份及清单的保存政策待确认，暂不开自动清理。
- 一个账号最多参加一个未结束小组；默认 14 天、预设 14／28／56、自定义 14–90；极高强度单独确认。完整规则看 PRD／总控，既有视觉保持。
- 本地模式仍用明确标记的开发码；原 `test` 模式仍只接受体验码；新增 `sms-trial` 要求独立持久库、精确 HTTPS origin、PNVS 适配与 1–20 的明确全站日上限，只监听回环供 Nginx 反代，不通过放宽旧模式发布。
- 本机私有短信配置为 `var/private/sms-auth.env`；服务器为 `/etc/payathon-test/sms-auth.env`、root 0600，systemd 单独读取，不进入源码包或普通快照配置。本地及服务器均已离线预检通过；首个实际注册已证明应用当时能完成 PNVS 发送及核验；未做独立 RAM 策略审计。RAM 策略仅两项动作，示例见 `deploy/`。
- 服务器业务配置 `/etc/payathon-test/app.env`；每小时备份、每 5 分钟检查保持启用。手机试用快照不打包短信密钥／旧体验码配置；隔离恢复使用本机离线模式验证数据，不调用短信。当前备份未加密、无自动异地同步／外部通知，不能写成生产灾备完成。
