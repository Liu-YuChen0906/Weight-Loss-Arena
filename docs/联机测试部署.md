# 上秤 · 联机测试

更新：2026-10-15（北京时间）。[在线测试版](https://101.132.150.197)已部署到用户指定的 Ubuntu 云服务器，不依赖个人电脑保持开机。现为手机短信试用（真实手机号验证＋示例身体数据），未开放真实健康数据或产品收费。

## 怎么体验

手机打开 [手机登录](https://101.132.150.197/#login) → 输入本人手机号 → 点击获取验证码（真实短信会计费） → 输入六位验证码 → 完成年龄及数据说明确认 → 用示例昵称／身高／体重体验组队。全站每天最多 10 次短信发送请求，失败／未知结果也计入；每个手机号仍有 60 秒冷却与次数限制。真实收码和设备流程由用户亲自验收，助手未代发短信。

2026-10-15 用户授权清空旧数据并部署：原 6 个在线账号及关联小组／记录／会话已清空，原 8 个体验码撤销。新的独立手机号库起始为空，不迁移旧身份。旧私有备份与本机旧体验账号资料保留，不能用于当前站点登录，不自动恢复。正式健康数据和产品收费仍未开放。

## 维护入口

SSH 主机指纹保存在本机私有 `var/test/known_hosts`。项目根目录连接：

```sh
ssh -o UserKnownHostsFile=var/test/known_hosts root@101.132.150.197
```

服务器上查看运行状态：

```sh
systemctl status payathon-test.service
journalctl -u payathon-test.service -n 50 --no-pager
systemctl list-timers payathon-cert-renew.timer
curl -fsS https://101.132.150.197/api/v1/health
```

`deploy/` 保存首次环境准备、先检查后激活的发布脚本、Nginx／systemd 配置和只读持久化核对脚本。后续发布保留已有 HTTPS、账号配置与数据库；首次准备脚本不用重复运行。打包要排除 macOS 元数据，且不能包含 `var/`、`.env`、体验码明文或 `.git/`：

```sh
COPYFILE_DISABLE=1 tar --no-xattrs -czf /tmp/payathon-test-release.tgz apps packages db scripts tests deploy package.json package-lock.json .node-version
```

旧 `scripts/online-check.mjs` 仅用于有已签发体验码的 test 环境，不能再对当前短信试用站运行。`scripts/sms-trial-browser-check.mjs` 在隔离内存库／替身 PNVS 验证手机页面完整流程，不发送真实短信；Playwright 路径沿用 README。首次短信切换脚本为 `deploy/install-sms-trial.sh --reset-legacy-test`，仅本轮授权使用，拒绝覆写已存在的新手机试用库；后续发布保留新库、清单及短信配置，不重复重置。
