# 秤群结队 · 开发流程与经验

整理：2026-10-14。用于后续开发复用；当前进度只维护在[交接入口](开发交接.md)，逐批事实与截图放[开发记录](本地基础版开发记录.md)，不在这里复制流水账。

## 一批修改如何闭环

1. 从用户批注、当前页面和对应规范确定问题；区分正式应用与静态原型，核对最新用户决定。只加载当前任务相关文档与代码。
2. 将本批需求写入对应规范，再落到正式代码。局部改动保持其他流程和文案；需要补充业务决定时，继续推进不依赖答案的工作。
3. 按变更选择检查：纯外观／动效以语法与浏览器验收为主；权限、记录、目标、日期、并发等业务修改必须补充或运行有意义的相关测试，不用重复实现细节的测试凑数。
4. 在实际服务页面刷新后验证：触发动作 → 结果／错误 → 切换或取消 → 刷新恢复。数据修改还要核对 API 和持久化；单凭界面或 WebSocket／HTTP 连通不算完整成功。
5. 保存必要证据并更新任务状态、交接和开发记录。向用户简短说明现在能体验什么、怎么验收、已通过检查和仍未验证的边界。

当前协作以用户体验和产品决定为核心，不要求用户阅读代码，也不为每次小改动另写长计划、架构稿或重复总结。

## 先确认自己改的是哪一份

正式预览是 `http://127.0.0.1:4180`，由 `apps/api/server.mjs` 直接读取 `apps/web/` 资源；当前没有构建步骤和自动热更新。改完必须刷新再看，不能把仍加载旧代码的截图当作验收结果。

`prototype/index.html` 与 `prototype/mobile.html` 是保留的设计工具；不要在其中修正式应用问题。过去移动原型的 iframe 缓存曾造成旧样式误判，核对原型时直接看实际页面入口。用户把静态页面作为参考时，先比对参考，不擅自修改它来消除差异。

旧总控中的固定邀请码、localStorage、默认 21 天等描述属于原型历史，不代表正式应用当前能力；反过来也不能将正式本地服务写成已经上线。

## 动效的关键不是只加 transition

- 单位切换保留表单与滑块节点，只更新选中态、数值、单位和目标；整页 `innerHTML` 重建会中断位移、焦点与输入。
- 范围和维度使用共享 `pillControl`／`selectPill`；`mountShell` 保留同一用户、同一房间内的导航，图表只更新数据区域。跨用户／跨房间不能为了动画保留旧私有内容。
- 外层滑块用 transform 负责连续位移，内层负责轻微拉伸回弹，文字短暂过渡。反向切换从当前位置衔接，不排队播放。
- 范围读请求不锁死筛选；`viewRequest` 排除过期响应，`dataRange` 用于失败回退。只读筛选的响应策略不能照搬到开营／保存等写操作；后者仍需权限、版本、幂等与未知结果核对。
- 尊重 `prefers-reduced-motion`，关闭位移与拉伸。样式存在降级规则不等于已经在真实系统设置下实测。
- 桌面纵向、手机横向的布局切换也会触发 transform 过渡；若截图刚好停在中间帧，先核对最终落点再判断布局错误，不要据此随意加偏移补丁。

代码位置见 `apps/web/app.js` 的 `switchRecordUnit`、`pillControl`、`selectPill`、`mountShell`、`refresh`，以及 `apps/web/styles.css` 末尾对应规则。

## 输入和数值不要被展示反向污染

记录内部以公斤 `recordKg` 保存原始输入值，斤只做 ×2／÷2 的展示换算；不要从已经四舍五入的显示字符串反复换算。实际验证曾用 60.125 kg 往返切换，展示 60.13 kg 后再切斤仍应为 120.25，不能累积舍入误差。

单位切换不保存；查看修改确认不保存；取消保留输入，刷新以数据库为准。界面 QA 优先只读交互，不为了截图覆盖用户已有记录。确需写入时使用隔离测试数据，明确提交前后与清理策略。

## 浏览器验收怎么做

- 先看真实页面、账号和当前路由；批注里的 URL 可能比当前状态旧。已有浏览器标签应按实际标签继续操作，不能只凭旧 URL 断言页面。
- 使用本轮可用的浏览器工具检查页面；重新绑定当前浏览器／标签，不把旧聊天的工具变量、标签 ID 或 PID 当成永久标识。
- 检查按钮选中态、焦点、快速往返、图表单位和数值、返回路径，以及固定操作区与导航的间距；不要只看一张静态截图。
- 响应式验证报告 DOM 测得的 CSS 宽度。本轮浏览器缩放使请求 330 宽实际为 375；不能把请求尺寸当作实测尺寸，也不能将 429 写成精确 430。
- 移动端关注横向溢出、三项是否同排、数值截断和底部按钮遮挡；桌面关注侧栏布局与纵向落点。临时视口验收后恢复用户尺寸。
- JavaScript 动画 API 在当前浏览器的只读 DOM 代理中可能不可用；不要反复调用不支持的 `getAnimations()`。用已支持的 DOM、截图与实际交互作证，明确未测部分。
- 连续动效在预览中体验，截图记录最终外观；实机键盘、安全区和系统偏好必须单独取得证据。
