## 3 视觉方向

整体是清爽、克制的移动端记录产品：近白底色、白色卡片、珊瑚红操作色、灰色辅助信息。用字号、间距和分组表达层次，减少装饰、重复标题与解释性文字。

### 尺寸与适配

- 移动端为主要呈现，独立预览默认 390 × 844，并提供 375、430 px 宽度切换。
- 响应式断点为 760 px。移动端常规页面水平内边距 20 px，内容为单列。
- 桌面最大宽度 1120 px，左侧导航 200 px，导航与内容间距 48 px；表单区域最大宽度 560 px。
- 移动端底部导航固定，三等分胶囊轨道，包含安全区域留白；浅灰底与白色选中块，当前项用主色图标和文字表示。切换小组／记录／数据时白色块约 420 ms 平滑滑动，轻微拉伸并柔和回弹，保留导航节点以连续衔接；桌面侧栏沿纵向滑动。尊重减少动态效果设置，不引入玻璃外观。
- 创建、加入邀请码、大厅的主要操作使用独立底部固定操作区，内容预留空间。记录页保存区固定在底部导航上方。
- 「我的准备」卡片跟随内容自然高度，不用大块空白固定高度来稳定底部按钮。
- 身高与体重输入隐藏上下微调箭头，使用数字键盘提示；返回按钮为 44 × 44 px 圆形按钮和线性左箭头，手机上隐藏「首页」等文字。

## 4 导航与页面结构

未加入小组时：首页 → 创建小组 → 创建确认 → 组队大厅；或首页 → 输入邀请码 → 加入详情 → 组队大厅。

大厅不展示开始后的导航。开始后底部固定 **小组、记录、数据**；个人分析是小组的下级页面，导航仍选中「小组」。不再有独立「分析」或「我的」Tab。

| 页面 ID | 页面／状态 | 进入方式 | 返回或后续 |
| --- | --- | --- | --- |
| D01 | 首页 | 初次进入或返回首页 | 有未结束小组仅返回当前小组；否则创建／加入；次级入口保持可点 |
| D02 | 加入小组与邀请详情 | 首页加入、输入邀请码 | 返回；确认后去大厅 |
| D03A | 创建小组 | 首页创建 | 返回首页；确认创建后去大厅 |
| D03B | 组队大厅与准备 | 创建成功或加入示例 | 返回首页；确认开始后去小组 |
| D04 | 小组进行中 | 小组导航 | 成员个人分析、邀请 |
| D05 | 记录体重 | 记录导航 | 保存成功回小组 |
| D06 | 成员个人分析 | 小组成员头像或姓名、复盘成员 | 返回小组；打开记录明细 |
| D07 | 小组数据 | 数据导航 | 同页切换范围与维度 |
| D08 | 期末复盘 | 已结束小组状态 | 个人分析、再组一期 |

主要弹层：极高强度确认、创建确认、邀请、修改身高体重、开始确认、修改当天记录确认、记录明细。

## 5 逐页布局和交互

### D01 首页

全屏白底，产品名「上秤」居中。账号有待开始或进行中小组时，下方仅一个珊瑚红大按钮「返回当前小组」，不显示创建／加入大按钮；无未结束小组时，下方竖排「创建小组」「加入小组」，前者珊瑚红、后者浅红底红字。按钮文字居中，不附装饰箭头。

大按钮下方的历史小组、账号与支持、隐私等小按钮独立可点。状态以服务端 `currentRoomId` 为准，退出、结束或刷新后同步更新；只查看已结束历史，不算已有当前小组。

当前首页没有 Logo 图形、介绍段落、示例邀请、价格、数据卡、底部导航或场景工具。

### D02 加入小组与邀请详情

邀请码页：顶部圆形返回按钮、「加入小组」标题、邀请码输入卡、底部固定「查看小组」。空值就地显示「请输入邀请码」；当前 QY2026 对应有效示例，其他输入进入失效状态。

详情页：返回按钮与标题 → 小组信息卡 → 参与规则与确认卡。展示固定示例名称、等待开营、头像、人数／8、21 天与低强度。加入前不显示体重和曲线。规则包括本期体重和趋势组内可见，以及开营后不能退出、房主不能提前关闭。

勾选默认不选，「确认加入」在未同意、邀请失效或满员时不可用；失效／满员显示对应原因。确认后进入加入示例大厅。

注意：详情页本身仍保留「加入后才能查看组员的体重和趋势。」；被删除的是发起邀请弹窗中的额外提示框，两者不能混为一谈。

### D03A 创建小组

顶部返回按钮和「创建小组」。表单顺序如下，底部固定主按钮文案为「创建」。

| 模块 | 当前布局与交互 |
| --- | --- |
| 小组名称 | 单行选填，最多 24 字符；placeholder 为「晚饭后散步小队」，实际 value 为空 |
| 小组介绍 | 多行选填；有自然语言占位提示 |
| 本期天数 | 一行四项：14 天、28 天、56 天、自定义输入；默认选中 14 天 |
| 减肥强度 | 低／中／高／极高四列，附轻松记录／适度挑战／更高挑战／谨慎选择；默认低；仅极高弹出确认提示 |
| 创建 | 校验天数后打开信息确认弹窗 |

创建页名称、介绍输入框及未选中的天数、强度按钮使用 #D5C5C1 边框和 #FFFAF8 浅暖底，提高可操作区域辨识度；输入聚焦时显示珊瑚红边框与轻微光圈。强度选中使用珊瑚红边框、浅红底和内描边。

天数卡片大数字搭配小单位，选中使用红色边框、浅红底和右上对号。自定义直接输入，不另开输入框或额外说明卡；开始编辑时取消所有预设对号。输入过程中不报非法提示，失焦或提交时校验 14–90 整数；转去预设按钮时不抢先弹错。

极高强度弹窗只保留谨慎选择说明、确认和「暂不选择」。取消保留原选择，不显示「演示目标不构成实际减重建议」。

创建确认使用浅暖色信息区，分行核对名称、天数与强度，不展示起止日期说明。「确认创建」才生成房间，「返回修改」保留表单。

### D03B 组队大厅与准备

顺序：返回 → 小组名、天数／强度、待开始标签 → 可选介绍 → 成员卡 → 我的准备卡 → 固定开始操作区。

成员卡显示人数／8、邀请好友、头像、姓名、房主与准备状态；本人完成后显示目标。新建房间仅有一位未准备房主。

准备卡有两种内容：

- 未准备：标题旁显示中性「未准备」标签，整行珊瑚色「填写身高体重」按钮；不显示重复解释段落。点击后在底部面板填写身高 cm、起始体重 kg，确认目标并准备，不预填真实信息。
- 已准备：标题旁显示带勾的「已准备」标签，浅珊瑚结果区并排显示起始体重与目标体重，以箭头连接、目标值强调；底部为整行浅珊瑚「修改身高体重」按钮。按钮至少 48px 高，窄屏数值与单位不截断、不横向溢出；卡片自然高度。

校验为身高 80–250 cm、起始体重 20–300 kg；对应字段显示错误。生成失败保留原数据，成功后成员状态与准备卡同步更新。

不显示准备结果中的强度／天数重复行，也不显示「开营后目标锁定。」提示块。

修改入口打开手机底部面板，竖排两个输入框，底部「保存修改」「取消」。面板顶部有短横条，内部字段可滚动，底部动作不随字段滚走；现有手机面板高度为 500 px 并受视口限制。保存有效数据后重算目标，取消保留原值；不显示保存后更新目标的解释句。

底部房主按钮为「开始本期」。1 人、有未准备成员或不是房主时禁用，并显示简短原因；普通成员显示「等待房主开始」。准备卡内容高度可以变化，开始按钮位置保持固定。

### 邀请好友弹窗

白色圆角弹窗，标题「邀请好友」，一行分享说明，大号珊瑚红邀请码 QY2026，主按钮「复制邀请信息」。当前保留顶部关闭按钮。

点击复制使用浏览器剪贴板，失败时用提示展示邀请码。不显示「加入前不会展示成员体重。」及其提示底框。

### 开始本期确认弹窗

顶部「确认开始本期」，当前保留关闭按钮。中间为浅暖色日期卡：上方「本期记录」和 N 天标签，下方左右分列开始与结束日期，用细连接线衔接。

日期使用「M 月 D 日」大字，下面小字分别写年份／今天、年份／23:59 截止。避免把完整起止日期堆成灰色块里的两行粗字。

卡片下方保留开始后不能退出或提前关闭的说明。主按钮「确认开始」，次按钮「再等等」。确认时重新检查开营条件；若已跨过北京时间零点，重新显示日期供核对。取消不启动本期。

### D04 小组进行中

顶部小组名称，右侧「邀请 ↗」。下方是截止日期与时间进度卡，再下方是成员数据卡。不另放个人记录大卡、鼓励按钮或提醒工具。

进度卡分为截止日期行、进度说明行、6 px 进度条。进行中显示「第 X / N 天」「还有 N−X 天」；最后一天显示「今天结束」，结束后显示「已结束」，开始前显示「尚未开始」。进度按日序计算并限制在 0–100%。

成员行分为三部分：

1. 左侧头像、姓名及「今日已记录／今日未记录／多日未记录」标签。
2. 中间迷你折线，只展示，不可点击跳转。
3. 右侧最新体重，两位小数和 kg；下方「已减重／已增重」及无符号数值。

不足两条记录时变化为「数据不足」，无最新记录时体重为「—」。体重值是最近读数，是否今天更新由状态标签区分。点击头像或姓名进入该成员的个人分析。

### D05 记录体重

顶部只显示「记录体重」，不显示标题下的当天日期（2026-10-14 用户确认）。白色表单卡内依次为公斤／斤切换、大数字输入、本期目标。底部「保存记录」固定在三项导航上方。

公斤／斤选择器保留当前 999 px 胶囊圆角、浅灰底、白色选中块和珊瑚红选中文字。根据 2026-10-14 用户反馈，增加约 420 ms 的连续滑动：选中块轻微拉伸后柔和回弹，文字颜色短暂渐变，快速反向切换衔接当前位置。只参考 Apple 液态玻璃的流畅动效，不引入玻璃或透明外观。切换时保留表单和滑块节点、焦点及输入，立即同步单位、数值和目标，不因整页重绘打断动画；不触发保存。系统启用减少动态效果时关闭滑动和拉伸。

输入框使用 decimal 键盘提示，未填时占位为 00.00；今天已有记录时预填当天数值。单位切换同步转换当前输入和目标，内部保存单位为 kg、两位小数。0、负数、非有效数字显示就地错误。

正式本地应用结果未知时沿用现有表单：保留输入并暂设只读，原错误位置提示「尚未确认保存结果，请恢复连接后核对。」，主按钮改为「核对保存结果」。显式核对沿用原请求，同组导航往返保留状态；确认结果后恢复编辑及「保存记录」。服务端已确认保存、仅后续读取失败时提示「记录已保存，数据同步暂时中断」。不增加常驻说明卡、日期或离线自动提交；正常保存外观与现有胶囊动效保持一致。

目标区使用浅暖底，展示本期目标、N 天、目标数值和强度。当前没有日期选择、私密备注、补录操作或重新生成目标入口。

覆盖今天已有记录时，弹出「修改今日记录」，以 2026-10-14 用户提供的[静态页面参考截图](../evidence/record-edit-reference.png)为本轮视觉依据：两张等宽卡并排，左侧「原记录」暖灰底 #F7F5F4、旧数值灰色 #8B8589；右侧「修改为」浅珊瑚底 #FFF0EC、浅珊瑚描边，新数值珊瑚红 #CF4938，与主操作色一致。数字加大加粗，kg 用较小字号，中央轻量箭头表达由旧值修改为新值。不使用蓝／紫色卡片。标题与卡片之间留白，卡片与整行珊瑚红「确认修改」之间保留明显间距，下方居中「取消」。不加入日期、更新说明或顶部叉号；窄屏仍保持两卡并排。取消只关闭确认，不写入记录并保留录入值；确认继续调用现有版本校验与保存。布局参考截图，配色和旧灰／新珊瑚红的数值对照按用户后续反馈及静态源码修正；prototype/ 源码未改动。

保存后回小组，成员读数、曲线和分析使用同一份记录更新。

### D06 成员个人分析

从成员入口进入，顶部圆形返回按钮与「某某的数据分析」。没有独立分析导航、横向成员选择器或「某某的记录趋势」重复标题。

核心图表卡右上是紧凑胶囊形的近 7 天／近 28 天切换，圆角、浅灰底／白色滑块及滑动动效与 D05 单位选择器一致，下面为原始体重折线和姓名图例。默认近 28 天。实际记录按日期间隔绘制，缺失日期不补零；单条记录只显示一个点。点按数据点显示日期、体重与已有补录状态。

图表下方仅保留两张并排指标卡：记录天数、记录覆盖率。覆盖率分母从所选区间起点与成员加入日中较晚者开始，计算至当前日期；结束状态计算至截止日。

再下方为「记录明细」整行入口：左侧浅红图标和标题，右侧条数与细箭头，最小高度 60 px、圆角 14 px。点击打开独立底部面板，不在页面里折叠展开。

### D07 小组数据

底部导航名称为「数据」，页面标题为「小组数据」。它不是个人资料、个人目标汇总或账号设置页面。

页面只保留一张成员对比卡：

- 顶部左侧「成员对比」，右侧近 7 天／近 28 天，默认近 28 天；使用与记录页一致的胶囊圆角、浅灰轨道、白色滑块和珊瑚红选中文字。
- 下方一行三项维度：体重、体重变化、变化比例。默认体重变化；三等分胶囊轨道，选中块在三项间平滑滑动。
- 中间同一张折线图显示所有成员，成员最多 8 人，各有颜色，不另设成员选择框。
- 下方两列紧凑成员数值区：颜色短线、姓名、当前维度对应数值和单位。数值取该成员在当前时间范围内最后一条记录；无记录显示「—」。

| 维度 | 计算方式 | 单位与方向 |
| --- | --- | --- |
| 体重 | 每条记录的原始体重 | kg |
| 体重变化 | 当前记录 − 该成员本期首条记录 | kg；正数带 +，负数保留 − |
| 变化比例 | （当前记录 − 本期首条）÷ 本期首条 × 100 | %；带方向 |

时间范围和维度切换采用约 420 ms 的连续位移、轻微拉伸与柔和回弹，快速反向切换衔接当前位置。筛选控件持续挂载，图表和数值单独更新，焦点保留；范围请求期间仍可再次选择，只接受最新请求结果，失败时回到已加载的范围。减少动态效果设置下即时切换。仅参考 Apple 的流畅动效，不采用液态玻璃外观。

切换时间范围只过滤可见日期，不把变化基准重置为区间首条。横轴起点为范围起点与本期开始日中较晚者，终点为当前日期；已结束时终点为本期截止日。纵轴按当前全部可见数据自适应，跨过零值时显示零基准线。

图表只绘制真实记录点，缺失日期不补零，已有点之间连线。当前小组图表没有点按详情动作，仅有 SVG title；不能将个人图表的点按行为套用于小组图表。

不再显示独立「记录参与」卡片或参与进度条。当前无导出、排名、AI、平滑线或额外高级功能。

### D08 期末复盘

顶部「本期复盘」、本期起止日期和已结束信息。主色概况卡展示人数、约定天数和总记录条数；下方「小组记录参与」按覆盖率排序，同值并列，展示头像、姓名、记录天数／可记录天数和覆盖率。

## 7 交付边界与验收

### 文档与实现边界

本版本是当前静态页面的视觉与交互说明，不是新功能开发清单。源 PRD 中未出现在当前页面的商业化、提醒、补录和账号能力，不因旧文档提到过就恢复。

当前未接业务 API、数据库、登录、支付、短信、邮件或模型服务。目标算法为可替换静态逻辑。页面已移除原型说明文案，但这些实现边界仍然成立。

### 当前版本核对清单

- 首页主操作随当前小组状态切换：有未结束小组仅一个「返回当前小组」大按钮，否则创建／加入；次级入口仍可点，主按钮均不带装饰箭头。
- 创建名称实际为空；用户不填才采用默认名。
- 天数预设为 14／28／56，自定义是第四项本身；选择自定义时无预设残留对号。
- 输入第一位数字不报错；完成输入后校验范围与整数。
- 创建主按钮为「创建」，先确认信息再进入大厅。
- 减肥强度为低／中／高／极高四档；低、中、高不弹提示，极高确认后选中，取消不改变原选择。
- 准备成功后状态同步；修改入口为手机底部面板，取消保留原值。
- 准备卡不靠固定大高度占位；底部开始按钮不随内容高度移动。
- 最终确认开始才确定日期，并再次检查人数、准备状态和日期。
- 小组有截止日期与时间进度，成员变化文案为已减重／已增重。
- 迷你折线不可点击，成员头像或姓名进入个人分析。
- 个人分析无成员选择器，只有两项统计；明细为可关闭独立面板。
- 记录保存固定在导航上方；「修改今日记录」按参考截图显示并排暖灰／浅珊瑚卡、原记录／修改为、旧灰新珊瑚红的加粗数值及中央箭头、确认修改和底部取消。
- 导航为小组／记录／数据，数据页为小组同图比较。
- 小组维度切换同时更新轴标签、曲线、单位与成员数值；没有记录参与独立卡。
- 页面无高级功能、支付、订单、AI、指标说明或内嵌预览工具入口。

### 验证范围

本文依据当前 HTML、JavaScript、CSS 及本轮移动端浏览器预览整理。浏览器中已查看过主要页面与多项切换交互，但这不等同于真实手机键盘、安全区、辅助技术或完整业务联机验证。后续设备验收需关注键盘弹出时的固定操作区、窄屏长名称、8 人曲线和弹层滚动。
